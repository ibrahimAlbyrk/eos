---
description: "Tool — complete_milestone"
---

Hand in the project's milestone you work on, once its "Done when" holds. Eos checks it and then, as the user allowed, shows it, asks the user or sends it; you never send anything yourself.

- `key`: the milestone's key, as the brief lists it. Only the milestone at work is taken.
- `summary`: what was done and where it is, in a few plain sentences the user reads.
- `files`: paths of files the milestone carries, if any.

Your turn ends here. Once Eos is done with it, a message names the next milestone: work on that one. After the last milestone the run ends.
