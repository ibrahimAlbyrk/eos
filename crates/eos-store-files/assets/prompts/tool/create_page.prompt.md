description: "MCP tool — create_page"
---

Create a page in the project this chat works in, linked to this chat; it shows up in the user's page list right away. For material the user will want to keep and edit — a plan, research findings, a checklist of work — when they asked for it or it is clearly meant to outlive the chat. Not for routine status: say that in chat.

Returns `{ id, title, rev }`.
