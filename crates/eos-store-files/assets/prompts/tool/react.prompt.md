description: "MCP tool — react"
variables:
  - NO_REPLY_TOOL
---

Put one emoji on a message the user sent, as your reaction: the user sees it on their message. A new reaction replaces your earlier one on that message; an empty `emoji` takes it back.

When to use:
- An emoji is the whole answer: thanks (❤️), "seen, will do" (👍) before you simply start working.

When NOT to use:
- In place of an answer, a question back or a report.
- On every message, or as decoration beside a reply that already says it.

When the reaction is all you have to say, end the turn with {{NO_REPLY_TOOL}}.
