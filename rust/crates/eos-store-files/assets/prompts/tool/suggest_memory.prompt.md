---
description: "MCP tool — suggest_memory"
---

Suggest something worth remembering about the user. It is NOT saved — the user reviews every suggestion in Eos and keeps or dismisses it. Suggest only how the user wants agents to work with them, or who they are, when they said it as a standing rule ("from now on…") or made the same correction across separate tasks. Write one preference as a rule that opens with its situation ("When …, …", "Before …") or as a fact ("The user …"), with their reason if they gave one. Never secrets, facts about the product or codebase, one task's steps, or what is already in your system prompt.
