---
description: "MCP tool — send_to_machine"
---

Send files or folders from this Mac to another of the user's Macs paired with Eos. They land in ~/Downloads/Eos on that Mac, and nothing there is ever replaced — a file with the same name is kept beside it ("web 2.zip"). Waits up to a minute; a bigger copy carries on in the background, where the user sees it in the Transfer tab. Returns where everything landed, or how far it got. A Mac that doesn't match or isn't reachable is an error that lists the paired Macs.
