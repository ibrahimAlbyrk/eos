# Eos 0.1.3 — Eos updates itself

Eos 0.1.3 updates itself from now on, opens your claude.ai Artifacts right in the side panel, and uses far less CPU while agents work.

### Downloads
| Platform | File | Note |
|---|---|---|
| macOS (Apple Silicon) | `Eos-darwin-arm64.zip` | Signed and notarized |
| Windows x64 | `Eos-Setup-x64.exe` · `Eos-win32-x64.zip` | Unsigned — on first run choose **More info → Run anyway** |
| Windows ARM64 | `Eos-Setup-arm64.exe` · `Eos-win32-arm64.zip` | Unsigned — same as above |
| iPhone (Eos Remote) | `Eos-Remote-iOS-source.zip` | Build it with your own Apple ID — see Install |

### Highlights
- **In-app updates.** New versions download in the background — only the files that changed — and Eos asks before it restarts.
- **Artifacts in the side panel.** claude.ai Artifacts open in their own tab inside Eos, with a live preview on hover.
- **Lighter on your computer.** Animations, the window and the daemon do much less work, so Eos stays cool while agents run.

### New
- An update button appears in the header when a new version is ready, with what's new and a restart button.
- Restart now, or let Eos wait until running agents finish before it restarts.
- A new version that doesn't start is rolled back to the one you had.
- Settings › Updates shows your version and release notes, checks on demand, and can stop downloading updates automatically.
- Artifact links open in a side-panel tab; ⌥-click opens them on claude.ai instead.
- Hovering an Artifact link shows the live page in a small preview.
- The Artifacts tab lists every Artifact from each Claude account you've signed in with.

### Improved
- Plan usage shows at once when you open the account menu or Settings, and refreshes behind it; the usage rings glide to new values.
- Eos stops drawing while its window is hidden, minimized or covered.
- Working-agent animations and loading shimmers run on the GPU instead of redrawing the whole window.
- Dragging a split divider is about three times smoother.
- File search answers in a few milliseconds instead of re-listing the project each time.
- Opening a large or binary file in the viewer is instant.
- Building the symbol index no longer freezes Eos for seconds, and it uses a fraction of the memory.
- Claude panes in the Code view keep up with long sessions without re-reading the whole transcript.
- The weekly database cleanup no longer pauses Eos.
- The menu bar icon breathes for a few seconds, then holds still. (macOS)

### Fixed
- Symbol search and references work in the installed app — the symbol index was empty there.
- Scrolling up keeps loading older messages in chats with folded turns.

### Known issues
- Updating is new on Windows and hasn't been tried on a real PC yet; if an update fails, run the latest Eos Setup over it. (Windows)
- Windows builds aren't code-signed yet, so SmartScreen warns once on first run. (Windows)
- Pairing, file transfer and phone control aren't on Windows yet. (Windows)
- Agents' shell commands need Git for Windows; Eos shows a download link when it's missing. (Windows)
- Eos Remote isn't on the App Store or TestFlight: you build it in Xcode with your own Apple ID, and it pairs with a Mac. (iPhone)

### Install & upgrade
- **macOS:** unzip and move `Eos.app` to Applications, replacing the old one.
- **Windows:** run `Eos-Setup-<arch>.exe` — it installs for your user, no admin rights needed, and replaces an earlier version.
- **iPhone:** unzip `Eos-Remote-iOS-source.zip` and follow `ios/BUILD.md` (Xcode + your own Apple ID).
- **Updating:** install 0.1.3 by hand this once; from here on Eos updates itself.
