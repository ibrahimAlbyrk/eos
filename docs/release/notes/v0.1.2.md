# Eos 0.1.2 — A real installer on Windows

Eos 0.1.2 replaces the small Windows setup popup with Eos Setup: pick where Eos goes and which shortcuts you want, watch it install, and Eos opens when it's done.

### Downloads
| Platform | File | Note |
|---|---|---|
| macOS (Apple Silicon) | `Eos-darwin-arm64.zip` | Signed and notarized |
| Windows x64 | `Eos-Setup-x64.exe` · `Eos-win32-x64.zip` | Unsigned — on first run choose **More info → Run anyway** |
| Windows ARM64 | `Eos-Setup-arm64.exe` · `Eos-win32-arm64.zip` | Unsigned — same as above |
| iPhone (Eos Remote) | `Eos-Remote-iOS-source.zip` | Build it with your own Apple ID — see Install |

### Highlights
- **Eos Setup.** A designed installer in Eos's style takes the place of the setup popup that appeared and vanished without a word. (Windows)

### New
- Choose the install folder, with the free space shown; the default is your user's Programs folder. (Windows)
- Choose a Desktop shortcut, a Start menu shortcut and starting Eos when you sign in. (Windows)
- Installing shows progress, speed and time left, and can be cancelled — a cancelled install leaves nothing behind. (Windows)
- Eos opens by itself when the install finishes. (Windows)
- Uninstall Eos from Settings › Apps; your chats, settings and memories in your user folder stay. (Windows)

### Known issues
- Windows builds aren't code-signed yet, so SmartScreen warns once on first run. (Windows)
- Pairing, file transfer and phone control aren't on Windows yet. (Windows)
- Agents' shell commands need Git for Windows; Eos shows a download link when it's missing. (Windows)
- Eos Remote isn't on the App Store or TestFlight: you build it in Xcode with your own Apple ID, and it pairs with a Mac. (iPhone)

### Install & upgrade
- **macOS:** unzip and move `Eos.app` to Applications, replacing the old one.
- **Windows:** run `Eos-Setup-<arch>.exe` — it installs for your user, no admin rights needed, and removes an earlier 0.1.x install first.
- **iPhone:** unzip `Eos-Remote-iOS-source.zip` and follow `ios/BUILD.md` (Xcode + your own Apple ID).
- There's no auto-update: download new versions from this page.
