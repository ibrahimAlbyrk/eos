# Eos 0.1.5 — Windows updates install

Eos 0.1.5 fixes in-app updates on Windows, which stopped with "Couldn't update to 0.1.4".

### Downloads
| Platform | File | Note |
|---|---|---|
| macOS (Apple Silicon) | `Eos-darwin-arm64.zip` | Signed and notarized |
| Windows x64 | `Eos-Setup-x64.exe` · `Eos-win32-x64.zip` | Unsigned — on first run choose **More info → Run anyway** |
| Windows ARM64 | `Eos-Setup-arm64.exe` · `Eos-win32-arm64.zip` | Unsigned — same as above |
| iPhone (Eos Remote) | `Eos-Remote-iOS-source.zip` | Build it with your own Apple ID — see Install |

### Fixed
- In-app updates on Windows build the new version instead of failing with "no such file or directory". (Windows)
- The Windows zip uses standard folder paths, so it unpacks the same with any zip tool. (Windows)

### Known issues
- Swapping in an update and restarting hasn't been tried on a real Windows PC yet; if an update fails, run the latest Eos Setup over it. (Windows)
- The browser panel hasn't been tried on a real Windows PC yet. (Windows)
- With remote access on, the Mac stays awake while it's on power so your phone can reach it; the display still sleeps and locks. (macOS)
- Windows builds aren't code-signed yet, so SmartScreen warns once on first run. (Windows)
- Pairing, file transfer and phone control aren't on Windows yet. (Windows)
- Agents' shell commands need Git for Windows; Eos shows a download link when it's missing. (Windows)
- Eos Remote isn't on the App Store or TestFlight: you build it in Xcode with your own Apple ID, and it pairs with a Mac. (iPhone)

### Install & upgrade
- **macOS:** unzip and move `Eos.app` to Applications, replacing the old one.
- **Windows:** run `Eos-Setup-<arch>.exe` — it installs for your user, no admin rights needed, and replaces an earlier version.
- **iPhone:** unzip `Eos-Remote-iOS-source.zip` and follow `ios/BUILD.md` (Xcode + your own Apple ID).
- **Updating:** Eos 0.1.3 and later update themselves — only what changed is downloaded, and Eos asks before it restarts. On Windows, an update that stopped at 0.1.4 picks up 0.1.5.
