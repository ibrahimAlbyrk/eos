# Eos 0.1.0 — Now on Windows

Eos 0.1.0 is the first public release: the desktop app for macOS and, new in this release, Windows 10 and 11 on x64 and ARM64 — plus Eos Remote, to follow your agents from your iPhone.

### Downloads
| Platform | File | Note |
|---|---|---|
| macOS (Apple Silicon) | `Eos-darwin-arm64.zip` | Signed and notarized |
| Windows x64 | `Eos-Setup-x64.exe` · `Eos-win32-x64.zip` | Unsigned — on first run choose **More info → Run anyway** |
| Windows ARM64 | `Eos-Setup-arm64.exe` · `Eos-win32-arm64.zip` | Unsigned — same as above |
| iPhone (Eos Remote) | `Eos-Remote-iOS-source.zip` | Build it with your own Apple ID — see Install |

### Highlights
- **Windows support.** The same app and the same design on Windows 10 and 11, x64 and ARM64.
- **Agents in parallel.** An orchestrator splits a task and runs workers, each in its own git worktree.
- **Several Claude accounts.** When one plan hits its limit, Eos moves the running agent to the next sign-in.
- **Visual answers.** Agents answer with maps, tables, charts and cards instead of walls of text.

### What's in Eos
- Orchestrator and worker agents, each working in an isolated git worktree
- Live transcripts with side questions (`/btw`), background jobs and workflow runs
- Claude, ChatGPT (Codex) and Gemini sign-ins, with each plan's usage at a glance
- A profile and memories every agent knows you by, with optional nightly "dreaming"
- Pages, a built-in browser, a file explorer, and git changes with line comments
- Sync of your profile, memories, pages and templates between your computers
- Control another computer running Eos, and send files to it (macOS)
- Eos Remote: follow and steer your agents from your iPhone, paired by QR code through an end-to-end encrypted relay (iPhone)

### Known issues
- Windows builds aren't code-signed yet, so SmartScreen warns once on first run. (Windows)
- Pairing, file transfer and phone control aren't on Windows yet. (Windows)
- Agents' shell commands need Git for Windows; Eos shows a download link when it's missing. (Windows)
- Eos Remote isn't on the App Store or TestFlight: you build it in Xcode with your own Apple ID, and it pairs with a Mac. (iPhone)

### Install & upgrade
- **macOS:** unzip and move `Eos.app` to Applications.
- **Windows:** run `Eos-Setup-<arch>.exe` — it installs for your user, no admin rights needed.
- **iPhone:** unzip `Eos-Remote-iOS-source.zip` and follow `ios/BUILD.md` (Xcode + your own Apple ID).
- There's no auto-update: download new versions from this page.
